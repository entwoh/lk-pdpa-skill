# Contributing · දායක වීම · பங்களித்தல்

Thank you! This project serves ordinary Sri Lankans, so accuracy and clarity matter more than anything.

## Ground rules
1. **Every legal statement needs an official source** — the Act, the Amendment Act, a Gazette, or a DPA document (link it in the PR).
2. **Drafts stay labelled "draft"** until gazetted/final.
3. **Plain language first.** If a 15-year-old can't follow it, simplify.
4. **Official terms:** use ✔ terms in `references/08-glossary-trilingual.md`. Propose new terms with a source.
5. Keep `chatgpt/GPT_INSTRUCTIONS.md` under **8,000 characters**, and keep total knowledge files ≤ 20.
6. Never add content that helps track, profile or expose individuals.

## When the law changes
Follow `docs/MAINTAINING.md`: update `00-status-and-timeline.md` (incl. "Last verified"), the affected reference file(s), `GPT_INSTRUCTIONS.md` key facts, README status tables (all three languages), and `CHANGELOG.md`. Run the prompts in `evals/test-prompts.md`.

## Wanted
- Tamil and Sinhala proofreading by native speakers / legal translators
- Sector playbooks (tourism, telecom, transport, insurance, BPO/IT exports)
- Final DPA rules/regulations once published
